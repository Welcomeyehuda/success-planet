# ⭐ כוכב ההצלחה — Success Planet

Independent 3D browser-game prototype for iPhone and desktop. Hebrew RTL. This is **Alpha 0.1**, not a production learning platform.

## Play
Once GitHub Pages is enabled: https://welcomeyehuda.github.io/success-planet/

## Current demo
- Mobile touch arrows / desktop arrows and WASD
- Explore a 3D fantasy village; interact near buildings
- Avatar outfit color, simple shop, virtual coins and XP
- Separate example questions for the two child difficulty tracks
- Browser-local save only

## Important
- Demo only; no accounts, real child data, parent dashboard, or secure shared progress
- In-game coins are virtual and can be earned repeatedly in this demo; not production-safe
- Three.js is loaded from an external CDN, so an internet connection is required
- Do **not** add personal child data, secrets, passwords, or API keys to this public repository

## Deployment
GitHub Actions automatically deploys on pushes to `main`. If the first run requests Pages setup, go to **Settings → Pages → Build and deployment → Source: GitHub Actions**.
